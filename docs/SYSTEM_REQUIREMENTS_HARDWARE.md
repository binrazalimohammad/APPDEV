## System Requirements — Hardware

### Mobile device (Android)

- **Minimum**
  - **Android version / API**: Android 8.0+ (API 26+) recommended baseline for modern notification behavior
  - **RAM**: 3 GB
  - **Storage**: 300 MB free (APK + cache)
  - **Network**: Wi‑Fi or mobile data (required)
- **Recommended**
  - **Android version / API**: Android 10+ (API 29+)
  - **RAM**: 6 GB+
  - **Storage**: 1 GB+ free (smoother caching, images)

### Sensors / device features

- **Required**: Internet connectivity
- **Not required (unless you extend features)**: GPS, camera, NFC, fingerprint

### Development machine

- **Minimum**
  - **CPU**: 4 cores
  - **RAM**: 8 GB
  - **Storage**: 10 GB free (Android SDK + build cache)
- **Recommended**
  - **CPU**: 8 cores
  - **RAM**: 16 GB+
  - **Storage**: SSD with 20 GB+ free

### API level mapping (why it matters)

- **API 26+**: notification channels (Android requirement) → used by local notifications.
- **API 28+**: improved background execution limits behavior.
